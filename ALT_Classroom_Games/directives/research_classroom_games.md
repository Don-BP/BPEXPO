# Directive: Research ALT Classroom Games

## Goal
Identify and catalog popular classroom games used by Assistant Language Teachers (ALTs) in Japanese elementary and junior high schools to teach English.

## Context
- **Company**: Brain Power (dispatch company for ALTs)
- **Target Audience**: Public elementary and junior high school students in Japan
- **Teaching Context**: ALTs work alongside Japanese Teachers of English (JTEs)

## Research Areas
1. **Analog Games** - Games using physical materials (cards, paper, chalk)
2. **Digital Games** - PowerPoint games, software-based activities
3. **Game Categories**:
   - Teacher-led games (ALT manages from front of class)
   - Student-to-student games (peer interaction)
   - Vocabulary games
   - Grammar games
   - Speaking/conversation games

## Known Examples
- Jeopardy
- Tornado Game
- (More to be discovered)

## Outputs
Create a structured document in `.tmp/games_research.md` containing:
- Game name
- Description and rules
- Original format (analog vs digital)
- Materials required
- Grade level suitability
- Digital conversion feasibility
- Notes on enhancement opportunities

## Execution
1. Web search for "ALT classroom games Japan"
2. Search for "ESL games elementary school"
3. Search for "PowerPoint games English teaching"
4. Search for "ALT Tornado game", "JET Programme classroom activities"
5. Compile findings into structured markdown
