# ALT Classroom Games Research Findings

## Overview
Research compiled from multiple sources on games used by Assistant Language Teachers (ALTs) in Japanese elementary and junior high schools.

## Game Categories

### 1. Teacher-Led Games (Analog → Digital Conversion Priority: HIGH)

#### Tornado Game ⭐️ HIGH PRIORITY
- **Type**: Review game with risk/reward mechanics
- **Original Format**: Grid drawn on board or PowerPoint
- **Materials**: Grid with hidden points and "tornado" squares
- **How It Works**: Teams choose squares, answer questions; correct answers reveal points, but hitting a "tornado" wipes their score
- **Digital Potential**: ★★★★★ Perfect for digital conversion
- **Enhancement Ideas**: 
  - Animated tornado effects
  - Sound effects
  - Customizable question banks
  - Visual themes (space, ocean, jungle)
  - Teacher edit mode for questions

#### Jeopardy ⭐️ HIGH PRIORITY
- **Type**: Quiz game (TV game show format)
- **Original Format**: PowerPoint with hyperlinks
- **Materials**: Question categories, point values
- **How It Works**: Teams select categories and point values, answer questions
- **Digital Potential**: ★★★★★
- **Enhancement Ideas**:
  - Daily Double animations
  - Buzzer sound effects
  - Auto-scoring
  - Timer option
  - Category customization

#### Vocabulary Karuta ⭐️ HIGH PRIORITY
- **Type**: Speed-based card matching
- **Original Format**: Physical flashcards spread on desk/floor
- **Materials**: Vocabulary flashcards
- **How It Works**: Teacher calls word, students race to tap/grab the card
- **Digital Potential**: ★★★★★ Excellent for tablets
- **Enhancement Ideas**:
  - Cards appear on screen, students tap quickly
  - Multi-player support (2-4 players per device)
  - Audio pronunciation
  - Score tracking
  - Different difficulty levels

#### Mystery Box / Lucky Box
- **Type**: Points reveal game
- **Original Format**: PowerPoint
- **Materials**: Boxes hiding points or consequences
- **How It Works**: Students answer question, then choose box to reveal reward
- **Digital Potential**: ★★★★☆

#### Hidden Picture Game
- **Type**: Vocabulary guessing
- **Original Format**: PowerPoint with shapes covering image
- **Materials**: Images, overlay shapes
- **How It Works**: Remove shapes progressively, students guess the word
- **Digital Potential**: ★★★★★

### 2. Student-to-Student Tablet Games (Original Digital Design)

#### Questions Bingo
- **Format**: Students create bingo cards with yes/no questions
- **Interaction**: Students walk around asking questions, get signatures for "yes"
- **Digital Version**: 
  - Generate random bingo cards
  - Digital stamp/signature system
  - Timer mode

#### Shiritori (English Word Chain)
- **Format**: Word chain game (last letter → first letter)
- **Interaction**: Team-based or peer-to-peer
- **Digital Version**:
  - Validate English words automatically
  - Show word history chain
  - Timer per turn
  - Dictionary integration

#### Pictionary
- **Format**: Drawing and guessing
- **Interaction**: Team vs team
- **Digital Version**:
  - Touch drawing canvas
  - Word bank customization
  - Timer
  - Guess submission system

### 3. Quick Warm-Up Games

#### Criss-Cross / Row and Across
- **Type**: Stand up, answer, sit down
- **How It Works**: Student answers correctly, chooses row or column to sit
- **Digital Potential**: ★★★☆☆ (More physical activity focused)

#### Fly Swatter
- **Type**: Physical speed game
- **Original Format**: Cards on board, students swat with fly swatters
- **Digital Version**: ★★★★☆ Touch-screen version possible

#### Stand Up & Shout
- **Type**: Vocabulary recognition
- **Digital Version**: Could work as quick tablet drill

### 4. Board/Card Games (Traditional → Digital)

#### Snakes and Ladders
- **Digital Potential**: ★★★★★
- **Features**: Dice roll, question on each space, automatic movement

#### Memory/Matching Game
- **Digital Potential**: ★★★★★
- **Features**: Card flip animations, matching pairs, timer

#### Taboo
- **Digital Potential**: ★★★★☆
- **Features**: Word display, taboo word list, timer

## Technical Requirements

### Teacher Edit Mode Features
- Add/edit questions
- Select categories
- Adjust point values
- Save/load question sets
- Export/import functionality

### Student Tablet Requirements
- Touch-friendly interface
- Works on iPad (Safari)
- Works on Chromebook (Chrome)
- Responsive design
- No login required (quick play)

### Visual Design Requirements
- Bright, vibrant colors
- Smooth animations (CSS/JavaScript)
- Sound effects (optional toggle)
- Clear, readable fonts
- Engaging graphics

### Art Asset Needs
- Game title headers
- Button designs
- Background patterns
- Character mascots (optional)
- Category icons
- Point/reward badges
